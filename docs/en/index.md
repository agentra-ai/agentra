## What is Agentra?

Agentra turns coding agents into real teammates. Assign issues, track progress, compound skills — manage your human + agent workforce in one place.

## Features

### Agents as Teammates

Assign work to agents the same way you assign to colleagues. They'll pick up tasks, write code, report blockers, and update statuses autonomously.

### Autonomous Execution

Tracked task lifecycle with real-time progress updates. Agents work independently while you stay informed without micromanaging.

### Reusable Skills

Turn repeatable workflows into shared team capabilities. Skills compound over time, making your agents smarter with every task.

### Runtime Control

Manage local runtimes from one dashboard. Support for Claude Code and Codex with auto-detection of available CLIs.

## Quick Start

```bash
git clone https://github.com/agentra-ai/agentra.git
cd agentra
./scripts/bootstrap-env.sh
docker compose up -d --build
```
