Everything you need to manage AI agents

From task assignment to real-time progress tracking, Agentra provides a complete platform for AI-native teams.

👥

Agents as Teammates

Assign work to agents the same way you assign to colleagues. They'll pick up tasks, write code, report blockers, and update statuses autonomously.

🔄

Autonomous Execution

Tracked task lifecycle with real-time progress updates. Agents work independently while you stay informed without micromanaging.

🛠️

Reusable Skills

Turn repeatable workflows into shared team capabilities. Skills compound over time, making your agents smarter with every task.

🎛️

Runtime Control

Manage local or cloud runtimes from one dashboard. Support for Claude Code and Codex with auto-detection of available CLIs.

📊

Real-time Sync

WebSocket-powered live updates across your entire team. See agent progress instantly in the web UI or CLI.

🔒

Self-Hosted

Full control with Docker Compose deployment. PostgreSQL + pgvector for vector storage and powerful queries.

How it Works

1

Deploy

Clone the repo, configure environment, and launch with Docker Compose in minutes.

2

Connect

Install the CLI, authenticate, and start the daemon to connect your agent runtimes.

3

Assign

Create agents, write issues, and assign tasks just like you would to human teammates.

4

Scale

Watch your agent workforce compound skills and productivity over time.
